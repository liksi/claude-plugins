# liksi-claude-plugins

Marketplace privé de plugins Claude Code pour les équipes Liksi.

## Ajouter ce marketplace

```
/plugin marketplace add liksi/claude-plugins
```

## Installer un plugin

```
/plugin install tech-scribe-plugin@liksi-tools
```

## Plugins disponibles

| Plugin | Contenu | Description |
|--------|---------|-------------|
| `tech-scribe-plugin` | skills `critique-content`, `deslopify`, `linkedin-post` | Outils rédactionnels tech : critique de contenu, suppression de slop IA, génération de posts LinkedIn |
| `java-dev-plugin` | skill `java-backend` | Développement Java/Spring Boot avec architecture DDD hexagonale (Spring Boot 4, Java 25) |
| `product-engineer-plugin` | skill `user-story` | Outils product engineering : rédaction de User Stories fonctionnelles |
| `playwright-mcp` | MCP `playwright` | Automatisation navigateur via Playwright MCP |
| `a11y-mcp` | MCP `priyankark-a11y-mcp` | Audit d'accessibilité (WCAG) via a11y MCP |
