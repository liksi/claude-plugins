# liksi-claude-plugins

Marketplace privé de plugins Claude Code pour les équipes Liksi.

## Ajouter ce marketplace

```
/plugin marketplace add liksi/claude-plugins
```

## Installer un plugin

```
/plugin install code-review@liksi-tools
```

## Plugins disponibles

| Plugin | Description |
|--------|-------------|
| `code-review` | Revue de code orientée Software Craftsmanship |
